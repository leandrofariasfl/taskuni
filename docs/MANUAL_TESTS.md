Este documento registra os testes executados manualmente durante o desenvolvimento do projeto.

Uma funcionalidade não deve ser considerada concluída apenas porque funcionou no cenário principal. Também devem ser verificados entradas inválidas, coleções vazias, registros inexistentes, valores limite, duplicidades e relações inválidas.

## Critérios mínimos por funcionalidade

Antes da revisão, confirmar pelo menos:

- cenário normal;
- entrada inválida;
- coleção vazia;
- registro inexistente;
- valores limite;
- dados duplicados, quando aplicável;
- relações inexistentes ou incompatíveis, quando aplicável;
- persistência após uma alteração bem-sucedida;
- ausência de alteração dos dados quando a operação for inválida.
